# Pacote de Handoff — Portal Cícero João

Este diretório contém **tudo** o que é necessário para reproduzir, em qualquer
outro ambiente (Replit, Next.js, WordPress, etc.), o portal institucional de
**Cícero João da Silva** — Sorocaba/SP.

Repositório de origem: `parlegis-cicerojoao`
Stack de origem: React 19 + TanStack Start + Tailwind CSS v4 + shadcn/ui

## Regras inegociáveis

1. Nunca escrever **"vereador"** (nem "vereadora", "Câmara Municipal" como cargo).
2. Nunca citar **partido político** (sigla, nome ou número).
3. Logo: usar **somente o símbolo CJ** no menu e o **wordmark** no rodapé —
   **sem a silhueta/skyline da cidade**.
4. Todos os números e dados devem sair de `03-DADOS.md`, sem inventar valores.
